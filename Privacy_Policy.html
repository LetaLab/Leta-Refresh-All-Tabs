Privacy Policy - Leta Refresh All Tabs

Last updated: August 2, 2026

Leta Refresh All Tabs is a browser extension for Chrome, Edge, Brave, and other Chromium-based browsers that reloads every open tab in every open window with one click, with three toggles for which windows to include and whether to bypass cache.

Summary

This extension does not collect, transmit, sell, or share any personal information. There is no analytics, no crash reporting, no telemetry, and no update-check pings of any kind - the extension never contacts any server, including one of its own. The only data it stores is your own toggle states (which windows to reload, whether to bypass cache, and whether the extension is turned on or off), and that data never leaves your browser.

What data is stored, and where

The extension stores four values, using the browser's built-in chrome.storage.sync API:

  • Whether the extension is enabled or disabled
  • Whether to reload the window you are currently viewing
  • Whether to reload other, unfocused windows
  • Whether reloads should bypass the cache

This storage is provided by the browser itself, not by us. If you are signed in to your browser, the browser vendor may sync this small setting across your own devices the same way it syncs your bookmarks. The extension developer never receives, sees, or has access to this data on any server, because no such server exists for this extension.

What the extension does

To decide which tabs to reload, the extension checks which browser window each open tab belongs to, then asks the browser to reload the tabs in the windows your toggles allow. It does not read tab URLs, page titles, page content, browsing history, or any personally identifiable information, and it does not run on, or inject anything into, any web page at all.

Link to letalab.eu

The extension's popup includes a plain link to letalab.eu, which opens in a new browser tab. The link itself carries no tracking script or tracking parameters - clicking it is no different from typing the address yourself. Once you're on that site, its own privacy practices apply, separately from this extension.

Third parties

We do not share data with any third party, because we do not collect any data to share. The extension embeds no third-party analytics, advertising, or tracking scripts, and loads no remote code - every file that runs is shipped inside the extension package itself.

Permissions

The extension requests exactly one permission, storage, to remember your toggle states. It does not request tabs, no host_permissions of any kind, no <all_urls>, no cookies, and no webRequest. This matches the README's Permissions table exactly.

Security

The extension's full source ships inside the package you install - nothing is downloaded or evaluated at runtime. We welcome responsible security review; if you find a problem, please report it privately and with enough detail to reproduce it, via the contact below.

Children's privacy

The extension is not directed at children and does not knowingly collect information from anyone, regardless of age, since it does not collect information at all.

Changes to this policy

If this extension's data practices ever change, this page will be updated before the change takes effect, and the "Last updated" date above will be revised accordingly.

Contact

Questions about this policy, the extension, or a security report can be sent via letalab.eu.
