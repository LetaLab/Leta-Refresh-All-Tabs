Privacy Policy — Leta Refresh All Tabs

Last updated: August 2, 2026

Leta Refresh All Tabs is a browser extension for Chrome, Edge, Brave, and other Chromium-based browsers that reloads every open tab in every open window with one click, with optional rules for which tabs to skip.

Summary

This extension does not collect, transmit, sell, or share any personal information. There is no analytics, no crash reporting, no telemetry, and no update-check pings of any kind — the extension never contacts any server, including one of its own. The only data it stores is your own reload preferences (which windows and which kinds of tabs to skip, and whether the extension is turned on or off), and that data never leaves your browser except through the browser's own, built-in sync.

What data is stored, and where

The extension stores a small set of on/off preferences, using the browser's built-in chrome.storage.sync API:

  • Whether the extension is enabled or disabled
  • Which windows to reload (the one you are viewing, other windows, or both)
  • Which kinds of tabs to skip (the active tab, pinned tabs, tabs playing sound, discarded tabs, incognito tabs)
  • Whether reloads should bypass the cache

This storage is provided by the browser itself, not by us. If you are signed in to your browser, the browser vendor may sync these small preferences across your own devices the same way it syncs your bookmarks — the extension developer never receives, sees, or has access to this data on any server, because no such server exists for this extension.

What the extension accesses

To decide which tabs to reload and which to skip, the extension reads a small set of state flags on your open tabs: whether a tab is the active one in its window, pinned, currently playing audio, discarded, or incognito, along with which window it belongs to. It then asks the browser to reload the tabs that match your settings. It does not read tab URLs, page titles, page content, browsing history, or any personally identifiable information, and it does not run on, or inject anything into, any web page at all.

Permissions

The extension requests exactly one permission: storage, to remember your preferences. It does not request the broader tabs permission, no host_permissions of any kind, no <all_urls>, no cookies, and no webRequest. Reloading a tab and reading the state flags listed above are both possible without any of those.

Optional keyboard shortcut

The extension defines an optional keyboard shortcut for the same reload action as the popup button. No key combination is assigned by default — it only does anything if you deliberately set one yourself at chrome://extensions/shortcuts. Using it does not access any data beyond what is described above.

Link to letalab.eu

The extension's popup and settings page include a plain link to letalab.eu, which opens in a new browser tab. The link itself carries no tracking script or tracking parameters — clicking it is no different from typing the address yourself. Once you're on that site, its own privacy practices apply, separately from this extension.

Third parties

We do not share data with any third party, because we do not collect any data to share. The extension embeds no third-party analytics, advertising, or tracking scripts, and loads no remote code — every file that runs is shipped inside the extension package itself.

Security

The extension's full source ships inside the package you install — nothing is downloaded or evaluated at runtime. We welcome responsible security review; if you find a problem, please report it privately and with enough detail to reproduce it, via the contact below.

Children's privacy

The extension is not directed at children and does not knowingly collect information from anyone, regardless of age, since it does not collect information at all.

Changes to this policy

If this extension's data practices ever change, this page will be updated before the change takes effect, and the "Last updated" date above will be revised accordingly.

Contact

Questions about this policy, the extension, or a security report can be sent via letalab.eu.
